# CampusLife — афиша мероприятий для школьного сообщества

Android-приложение (Kotlin + Jetpack Compose), которое собирает школьные события в одном месте:
лента с фото, поиск и фильтры, запись, избранное, напоминания, а для организаторов — создание событий и QR-коды.

> 🎥 Видео-демонстрация: [`demo/demo.mp4`](demo/demo.mp4)

## Основной функционал

| Раздел | Что умеет |
|---|---|
| **Лента (Афиша)** | Карточки с фото, названием, кратким описанием, датой, временем, местом и числом свободных мест. Нажатие открывает подробную карточку. |
| **Поиск и фильтры** | Поиск по названию; фильтр по категориям (Спорт, Творчество, Наука, Конкурсы); фильтр по датам: «Сегодня», «7 дней» или выбор любой даты в календаре. |
| **Запись** | Кнопка «Записаться» / «Отменить запись», контроль лимита мест, вкладка «Записи» со списком своих мероприятий. Организатору показывается число записавшихся и список участников. |
| **Избранное** | Сердечко на карточке и в деталях, отдельная вкладка «Избранное». |
| **Напоминания** | Уведомление за 15 минут / 1 час / 1 день до начала (WorkManager, запрос разрешения на уведомления для Android 13+). |
| **Режим организатора** *(усложнение)* | Включается в «Профиле». Создание события (название, описание, категория, дата, время, место, число мест), список записавшихся, удаление события. |
| **QR-коды** *(усложнение)* | **QR события** — участник сканирует и записывается на месте. **QR билета** — участник показывает билет, организатор сканирует и отмечает приход. |

## Стек

- Kotlin, Jetpack Compose, Material 3, Navigation Compose
- Room (локальная БД, демо-данные подгружаются при первом запуске), Kotlin Flow, ViewModel
- WorkManager (напоминания), Coil (изображения), ZXing (генерация QR), Google Code Scanner (сканирование QR, без запроса доступа к камере)
- minSdk 26, targetSdk 35

Сервер не требуется: все данные хранятся на устройстве. Демо-мероприятия и «чужие» записи создаются автоматически, даты — относительно текущего дня.

## Запуск

Нужны: Android Studio (Ladybug или новее) или JDK 17+ и Android SDK 35.

**Android Studio:** `File → Open` → папка проекта → дождаться синхронизации Gradle → `Run ▶` на эмуляторе или устройстве.

**Командная строка:**

```bash
echo "sdk.dir=/путь/к/Android/sdk" > local.properties
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug   # установка на подключённое устройство/эмулятор
```

Для загрузки фотографий и работы сканера QR нужен интернет и устройство/эмулятор с Google Play Services (образ «Google Play»).

## Как посмотреть сценарии

1. **Студент:** в ленте найти событие по названию/категории/дате → открыть → «Записаться» → ♥ → «Напомнить о событии» → вкладка «Записи» → «Мой билет (QR)».
2. **Организатор:** «Профиль» → включить «Режим организатора» → в ленте «+ Событие» → заполнить форму → открыть событие → «QR события» / «Сканер», смотреть список записавшихся.
3. **Регистрация по QR:** на одном устройстве открыть «QR события», на другом — иконка сканера в ленте. Для отметки прихода — «Мой билет» у участника и «Сканер» у организатора.

## Структура

```
app/src/main/java/com/campuslife/
├── MainActivity.kt          # навигация, нижняя панель
├── data/
│   ├── Data.kt              # Room: сущности, DAO, демо-данные
│   ├── AppViewModel.kt      # состояние, фильтры, запись, QR-логика
│   └── Utils.kt             # QR, напоминания, форматы дат
└── ui/
    ├── Components.kt        # тема, карточка события, QR-диалог
    ├── FeedScreens.kt       # лента, записи, избранное, профиль
    ├── DetailScreen.kt      # карточка события
    └── CreateScreen.kt      # форма создания события
```
